# بَنّاء Studio V31 — مكتبة الوسائط والعناصر المتقدمة

نسخة HTML مستقلة من محرر بناء المواقع. للتشغيل افتح `index.html` أو `Bunaa.html` مباشرة؛ لا تحتاج إلى Python أو Node أو npm أو خادم.

## تحرير العناصر على الشاشة
- حدّد أي عنصر واضغط عليه ثم اسحب مقابض الحواف لتغيير حجمه مباشرة من المعاينة.
- اسحب العنصر نفسه لتغيير موضعه دون فتح لوحة الخصائص.
- لتجميع عناصر، استخدم Shift أو Ctrl/Cmd وحدد العناصر المتجاورة من داخل الصفحة، ثم اضغط «تجميع المحدد». لفك المجموعة حدّدها واضغط «فك المجموعة».
- الصور تدعم تحديد الحجم المباشر واختيار «قص لملء المساحة» أو «إظهار الصورة كاملة».
- مكونات القوالب تبقى عقدًا مستقلة ويمكن تحديد كل جزء من المعاينة أو لوحة الطبقات.

## استخدام الوسائط
- اسحب الملفات إلى مكتبة الوسائط أو اختر عدة ملفات من الجهاز مرة واحدة.
- تُسمّى الملفات تلقائيًا حسب النوع، مثل `img1` و`video1` و`audio1` و`file1`.
- استخدم البحث والتصفية والمعاينة والتنزيل وتعديل الاسم والنص البديل.
- أدرج الملف كعنصر جديد أو اربطه بعنصر موجود. يمكن اختيار عدة ملفات بعلامات اختيار عادية دون Ctrl/Cmd.
- تُحفظ الملفات الكبيرة في IndexedDB عندما يدعمه المتصفح، لتخفيف حجم بيانات المشروع؛ يستخدم التطبيق مسارًا احتياطيًا للملفات الصغيرة إذا لم يتوفر ذلك.

## أنواع المحتوى المدعومة
- صور ومعارض صور وصور متتابعة.
- فيديو فردي وبطاقات فيديو ومعرض فيديو بمشغلات حقيقية.
- صوت وقائمة صوت قابلة للتشغيل.
- عارض PDF وبطاقة ملف عامة للتنزيل أو الفتح.
- شبكة وسائط مختلطة تضم الصور والفيديو والصوت والملفات.
- تضمين صفحة داخلية كاملة أو قسم/عنصر محدد أو نص فقط.
- كتلة HTML محدودة تُنقّى قبل العرض لمنع السكربتات والروابط الخطرة.

## التصدير
يحتوي تصدير الموقع على ملفات HTML للصفحات، CSS وJavaScript، وملفات الوسائط الفعلية داخل `assets/`، إضافة إلى manifest وsitemap وrobots وملف 404.

## ملفات التطوير
يوجد المصدر المنظم في `source/src/` والـbundle المستقل في `source/bunaa.bundle.js`. يمكن إعادة بناء الملف المضمّن أثناء التطوير باستخدام:

```bash
python source/scripts/build_bundle.py
```

هذا الأمر مطلوب للتطوير فقط، وليس لتشغيل الموقع.
