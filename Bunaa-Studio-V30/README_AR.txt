بَنّاء Studio V30 — نسخة مستقلة
================================

التشغيل العادي (بدون GitHub وبدون Python أو Node.js):
1) فك ضغط الملف كاملًا.
2) افتح مجلد Bunaa-Studio-V30.
3) افتح index.html مباشرة في Edge أو Chrome، أو شغّل «تشغيل-المحرر.bat».
4) من شاشة الدخول استخدم «تجربة مباشرة بدون حساب».
5) أنشئ مشروعًا، ثم اضغط «معاينة» لفتح الموقع الفعلي في نافذة/تبويب مستقل.

المعاينة:
- تُولَّد صفحة HTML مستقلة من بيانات المشروع الحالية.
- تتضمن الصفحات والتنسيقات والتفاعلات المضمنة في المشروع.
- إذا منع المتصفح النوافذ المنبثقة، اسمح بفتح النوافذ لهذا الملف أو استخدم رابط الفتح الذي يظهر في نافذة البديل.

اختبار اختياري للمطورين:
- يتطلب Node.js حديثًا واتصال إنترنت لتنزيل Playwright ومتصفح Chromium.
- افتح الطرفية في هذا المجلد ثم نفّذ:
  npm install
  npx playwright install chromium
  npm run test:preview

الملف index.html هو التطبيق الكامل، ويمكن فتحه محليًا من دون تثبيت المتطلبات الاختيارية.
ملاحظة: المواقع الخارجية المضمنة (مثل YouTube) تحتاج إلى اتصال إنترنت بطبيعتها.
