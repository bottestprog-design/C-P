# تقرير مراجعة V30 — مكتبة الوسائط وعناصر المحتوى

## التغييرات
- تحسين سير العمل لرفع عدة ملفات، السحب والإفلات، المعاينة، البحث والتصفية، إعادة التسمية، النص البديل، التنزيل، الإدراج كعنصر جديد أو الربط بعنصر موجود.
- تسمية تلقائية بحسب نوع الملف (img/video/audio/file/font).
- إضافة Blob Store عبر IndexedDB للملفات الكبيرة، مع fallback للوسائط الصغيرة عند عدم توفر IndexedDB، لتجنب إدخال بيانات الملفات الكبيرة في LocalStorage.
- إزالة روابط العناصر عند حذف أصل الوسائط، وفحص مراجع المشاريع الأخرى قبل حذف Blob مشترك.
- دعم معرض صور، شبكة وسائط مختلطة، معرض فيديو، قائمة صوت، عارض PDF، بطاقة ملف عامة، وتضمين صفحة داخلية كاملة/جزء/نص فقط.
- تضمين ملفات الوسائط الفعلية عند تصدير ZIP، مع صفحات وملفات الموقع المعتادة.
- تحسين اختيار مجموعة وسائط باستخدام checkboxes بدل multi-select الذي يتطلب Ctrl/Cmd.
- تنقية كتلة HTML من script وiframe وخصائص الأحداث وروابط javascript: قبل العرض.

## تحقق آلي
- 50 وحدة مصدرية JavaScript: اجتازت `node --check`.
- 50 مرجع module داخلي، ولا يوجد module مفقود.
- `index.html` و`Bunaa.html`: ملف واحد مستقل لكل منهما، مع script داخلي واحد وstyle داخلي واحد، ولا توجد scripts خارجية أو inline event handlers.
- لا توجد IDs مكررة في HTML الفعلي.
- اختبار Chromium باستخدام محتوى HTML المستقل نفسه عبر `page.set_content()`:
  - إقلاع وتجربة مباشرة بدون Console/Page Errors.
  - رفع صورة وPDF وصوت، ومعاينتها، وربطها بعناصر مناسبة.
  - عرض فيديو محمّل في عنصر فيديو فعلي.
  - شبكة وسائط تضم أنواعًا متعددة.
  - تضمين صفحة داخلية بوضع كامل/قسم/نص.
  - فحص أمان HTML المدخل.
  - اختيار عدة ملفات لمعرض الصور دون Ctrl/Cmd.
  - حذف أصل الوسائط وتنظيف المراجع.
  - تصدير ZIP والتحقق من ملفات الصورة وPDF والصوت والفيديو داخله.

## ملاحظة اختبار بيئية
المتصفح في بيئة الاختبار يفرض قيودًا على التنقل المباشر إلى `file://` و`localhost`. لذلك شغّلت HTML المستقل ذاته داخل Chromium عبر `page.set_content()`، ولم أصف التنقل المباشر إلى عنوان محلي على أنه اختبار ناجح.

## التشغيل
افتح `index.html` مباشرة. أدوات Python/Node تُستخدم للتحقق وإعادة بناء المصدر فقط؛ لا توجد حاجة لها عند التشغيل اليومي.
