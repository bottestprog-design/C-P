# ابدأ مع بَنّاء Studio V31

1. فك الضغط.
2. افتح `index.html` في المتصفح. إذا كنت تريد اسم الملف بالعربية/الإنجليزية البديل، افتح `Bunaa.html`.
3. اضغط «تجربة مباشرة» أو أنشئ حسابًا محليًا.
4. لتغيير حجم عنصر، حدّده واسحب مقابض الحواف؛ لتحريكه اسحب العنصر نفسه. لتجميع عناصر، استخدم Shift أو Ctrl/Cmd لتحديد أكثر من عنصر ثم اضغط «تجميع المحدد».
8. افتح مكتبة الوسائط واسحب إليها الصور أو ملفات الصوت والفيديو وPDF وغيرها، أو اختر ملفات متعددة من الجهاز.
5. اضغط «إدراج كعنصر» لإضافة الملف إلى الصفحة، أو افتح خصائص عنصر موجود واختر الملف من المكتبة.
6. عند اختيار معرض أو شبكة وسائط، استخدم مربعات الاختيار الظاهرة بجانب كل ملف؛ لا تحتاج إلى الضغط على Ctrl أو Cmd.
7. صدّر الموقع من زر التصدير لتحصل على صفحات الموقع والملفات التابعة له داخل ZIP.

لا يتطلب التشغيل Python أو Node أو npm أو اتصالًا بالإنترنت. تستخدم الملفات الكبيرة IndexedDB عندما يكون متاحًا في المتصفح؛ إذ قد يحد المتصفح من التخزين عند فتح ملف محلي في بعض إعداداته.
