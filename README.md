# بَنّاء V11 — Phase 3

نسخة تطوير قوية مبنية على V11، بواجهة Canvas-first وتقسيم هندسي واضح.

## التشغيل

افتح `index.html` مباشرة أو شغّل `start-local.bat` لفتح المشروع عبر خادم محلي.

## ما تم تضمينه

- 40+ عنصرًا مسجلًا في Component Registry.
- 9 قوالب جاهزة كاملة، مع تطبيقها كموقع أو إضافة قسم.
- صفحات متعددة مع إدارة وإنشاء ونسخ وتسمية وحذف.
- Canvas متحرك وقابل للـZoom وFit وPan وScroll.
- أدراج جانبية للعناصر والطبقات والتفاعل والتخصيص.
- Inspector بسيط افتراضيًا ومتقدم عند الطلب.
- تخصيص أجهزة اختياري مع مزامنة ذكية.
- تفاعل بسيط + runtime فعلي داخل المحرر.
- معاينة حية عبر iframe/srcdoc.
- Undo/Redo + حفظ محلي + استعادة.
- مدير وسائط محلي.
- فحص جودة أساسي.
- تصدير HTML/JSON وZIP متعدد الصفحات.
- وضع المتدرب وعرض كود العنصر.

## التحقق

```bash
node verify.mjs
node tests/test-suite.mjs
```

لا توجد مكتبات خارجية مطلوبة.
