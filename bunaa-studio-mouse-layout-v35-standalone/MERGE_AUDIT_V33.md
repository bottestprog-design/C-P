## مشكلات أُصلحت في الدمج

1. **تغيير حجم الصور:** أصبحت أبعاد الصورة الفعلية تتبع أبعاد الإطار عند سحب مقابض التحجيم الثمانية؛ وتم حفظ الحجم في النموذج، وليس فقط في CSS المؤقت.
2. **استمرار السحب خارج العنصر:** أُضيف تتبع أحداث المؤشر على مستوى النافذة مع التقاط المؤشر، حتى تستمر حركة الماوس عند عبور حدود العنصر أو مساحة الرسم.
3. **مساحة العمل المتكيفة:** يتم تمديد عرض/ارتفاع مساحة العمل القابلة للتمرير عند تحريك العناصر أو تكبيرها، بدل حصر العنصر عند الحافة.
4. **سحابة الشعارات:** أزيل فرع renderer مكرر كان يلتقط النوع قبل renderer الأكثر اكتمالًا، فتظهر الآن الصور والعناوين والروابط.
5. **تطابق المعاينة والتصدير:** أضيفت سلوكيات التصفية والشرائح والسلة والنموذج المحلي إلى runtime المعاينة أيضًا.
6. **أصول التصدير:** تصدير المتصفح يضم الوسائط المحلية والمرفوعة ووسائط الإنترنت التي تسمح بها CORS، ويعيد كتابة المسارات ويُبقي الروابط الخارجية فعالة. أضيفت أداة اختيارية تعتمد Python للوسائط التي تعذر تنزيلها من المتصفح.

## حدود التصدير التي يجب إبقاؤها واضحة

روابط التنقل التي تقود إلى مواقع خارجية تبقى روابط ويب؛ لا تقوم الحزمة بنسخ تلك المواقع بأكملها. الصور والملفات الخارجية قد تتعذر إضافتها إذا تطلبت تسجيل دخول، أو منعها الخادم، أو كانت ضخمة/غير مدعومة؛ في هذه الحالة يحتفظ الموقع بالتقرير بدل الادعاء أن المورد تم تنزيله. أداة Python تحاول تنزيل الوسائط العامة التي يمكن الوصول إليها فقط، وتراجع تحويلات العناوين لتجنب الوصول إلى وجهات محلية/خاصة.
