# Bunaa Studio V34 — تقرير الاختبار النهائي

**التاريخ:** 2026-10-10  
**قاعدة العمل:** إصدار V33 المحلي؛ جميع مساراته محفوظة في الحزمة الجديدة.

## الإصلاحات

1. **المساحات الجانبية/ملاءمة العرض:** كانت مساحة الرسم تتحول من مركزها بينما حاوية التمرير تُحسب من الحافة، فينزاح المحتوى خارج المنتصف. صار التحويل من `top left` مع ملاءمة تلقائية عند فتح المحرر وتغيير قياس منطقة العمل، مع احترام التكبير اليدوي. تقلصت الفجوات في الاختبار إلى 25–31 بكسل لكل جانب بحسب العرض، بدل انزياح غير متناظر، ولم يظهر تجاوز أفقي لمستند التطبيق.
2. **HTML مستقل:** يوجد اختيار للصفحة الافتتاحية. الملف الناتج يضم جميع صفحات المشروع داخل ملف HTML واحد، وCSS وJavaScript والأنيميشن والموارد الممكن تضمينها؛ وتبدل روابط الصفحات الداخلية المحتوى داخل الملف نفسه بدل طلب ملفات HTML أخرى.
3. **ZIP كامل للموقع:** ينشئ HTML منفصلًا لكل صفحة، ويضم `styles.css` و`script.js` وبيانات المشروع والخرائط والوسائط المرفوعة والمتاحة، ويحوّل الروابط الداخلية إلى أهداف محلية صحيحة. يخضع ZIP لفحص CRC عند الاختبار.
4. **الاحتفاظ بالميزات السابقة:** لم تُحذف مسارات ملفات V33؛ بقيت الوحدات الـ49 ومحرر التدرج متعدد الألوان، والسحب والتحجيم بمقابضه الثمانية، والارتفاع المتكيف، ومعاينة الأجهزة، ومكتبة العناصر والتفاعلات وأداة استكمال الوسائط.

## الاختبارات المنفذة فعليًا

- `python tests/verify_project.py`: **20 مجموعة فحص تكامل ناجحة**؛ فحص 49 وحدة ومراجعها، تزامن HTML، IDs، JavaScript، ومكونات التحرير والتصدير.
- `CHROMIUM_PATH=/usr/bin/chromium python tests/editor_browser_test.py`: **13 مجال تحقق تفاعلي ناجح**، لا أخطاء `pageerror` أو Console؛ يشمل التدرجات، السحب، مقابض تغيير الحجم الثمانية، undo/redo، الأبعاد المتجاوبة، المعاينة والتفاعلات، تصدير الأصول، وعروض 1440 و1180 و900 و560 و390 و320 بكسل.
- `CHROMIUM_PATH=/usr/bin/chromium python tests/test_v34_export_browser.py`: اختُبر مشروع من صفحتين مترابطتين وصورة PNG مرفوعة وتفاعل حركة. HTML افتتح الصفحة المختارة، ونجح الانتقال بين الصفحات في الملف الواحد، وتم فك الصورة بنجاح. ZIP احتوى `index.html` و`about.html` وCSS وJavaScript و`project.json` والملف الفعلي داخل `assets/` مع مسارات صحيحة وفحص CRC سليم.
- ملاءمة مساحة العمل اختُبرت بعد تغيير حجم نافذة المحرر: عرض منطقة الرسم كان أضيق من viewport، والهوامش متوازنة عند العروض 1180 و900 و560 و390 و320 بكسل.
- `python tests/test_complete_export_assets.py`: اختبار الأداة الاختيارية لاستكمال الوسائط الخارجية **نجح باستخدام خادم اختبار محلي محاكى**.
- `node --check bundle-extracted.js`: ناجح.

## نتيجة الحفاظ على الملفات

مقارنة آلية مع `bunaa-studio-mouse-layout-v33-standalone.zip`: كل **78 من 78** مسارًا سابقًا ما زالت موجودة؛ لم يفقد الإصدار أي مسار. التغييرات المقصودة موضحة في `MERGE_AUDIT_V34.md`، وأضيفت التقارير ونتائج الاختبارات الجديدة.

## الحدود التي لم أدّعِ اختبارها

- لم يُجر اختبار حي لتنزيل أصول محمية أو خاضعة لجلسة دخول من جميع مواقع الإنترنت. قيود CORS أو المصادقة أو منع التنزيل من المصدر الخارجي قد تمنع تضمين بعض الملفات؛ يبيّن المشروع هذه الحالات في `EXTERNAL_RESOURCES.md` ويمكن تجربة أداة الاستكمال الاختيارية، لكنها لا تضمن نسخ مواقع خارجية كاملة.
- اختُبر التصدير على مشروعين مترابطين مُنشأين للاختبار وعلى أصول محلية/مضمنة؛ هذا لا يثبت كل تركيبة بيانات مستقبلية ممكنة. الروابط الخارجية العادية محفوظة كروابط تنقل وليست صفحات يجري نسخها تلقائيًا.

## طريقة التشغيل

فك ضغط الحزمة وافتح `OPEN_FIRST.html` أو `index.html` في متصفح حديث. لا يلزم GitHub أو Node.js لتشغيل المحرر. ملف ZIP المكتمل هو **الموقع الذي صممه المستخدم** وليس نسخة من ملفات GitHub.
