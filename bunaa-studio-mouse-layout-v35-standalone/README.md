# Bunaa Studio V35 — نسخة مستقلة

محرر مواقع يعمل محليًا من دون اتصال GitHub أو تثبيت Node.js. ابدأ من `OPEN_FIRST.html` أو `index.html`.

## سياسة مساحة العمل V35

- عرض لوحة التحرير ثابت حسب الجهاز النشط (سطح المكتب/لوحي/هاتف). لا يوسّع عنصر عريض اللوحة ولا يعيد توزيع العناصر الأخرى. قد يظهر تجاوز العنصر داخل مساحة اللوحة القابلة للتمرير، لكنه لا يغيّر عرض إطار الجهاز.
- الارتفاع الإضافي لا يُحسب مجددًا من جميع العناصر عند كل تحديث أو تحريك أو تغيير عرض النافذة. يبدأ بارتفاع أساسي 360px. لا يُسجّل امتداد إضافي إلا عندما يغيّر المستخدم ارتفاع عنصر بمقبض رأسي ويتجاوز الجزء السفلي للعنصر الحد الحالي. يخزن الامتداد لكل صفحة وجهاز، ولا ينكمش تلقائيًا عند تصغير العنصر.
- إعادة ملاءمة التكبير عند تغيير حجم نافذة المحرر تغيّر مستوى التكبير فقط، لا عرض اللوحة المنطقي.

## الميزات المحفوظة

تحرير العناصر، السحب، ثمانية مقابض تغيير الحجم، التراجع والإعادة، عرض الأجهزة الثلاثة، المعاينة التفاعلية، تدرجات متعددة الألوان، مكتبة المكونات، صفحات الموقع، التفاعلات، وتصدير HTML مستقل متعدد الصفحات أو ZIP كامل.

## تحقق V35

اختُبر تغيير عرض عنصر إلى أكثر من عرض الجهاز من دون توسيع اللوحة، ونقل عنصر إلى خارج الحد دون تمديد تلقائي، وتمديد الارتفاع بمقبض رأسي، وبقاء الارتفاع المسجل بعد تقليص العنصر. اختُبرت كذلك صادرات HTML/ZIP ووسائطها، وعروض الشاشة من 320 إلى 1440px. راجع `QA_REPORT_V35.md` و`MERGE_AUDIT_V35.md`.
