# ابدأ هنا — Bunaa Studio V35

1. فك ضغط ZIP كاملًا.
2. افتح `OPEN_FIRST.html` في المتصفح. إن لم يعمل دليل البدء التلقائي، افتح `index.html`.
3. اختر/أنشئ مشروعًا محليًا وابدأ التحرير. لا تحتاج إلى ربط GitHub ولا إلى تثبيت Node.js.

## سلوك عرض اللوحة

عرض اللوحة ثابت حسب الجهاز. تكبير عنصر عريض لا يمدد الصفحة أفقيًا ولا يحرك عناصر أخرى تلقائيًا. الارتفاع الأساسي 360px، ولا يُضاف ارتفاع محفوظ إلا بعد تغيير المستخدم للارتفاع بمقبض رأسي وعندما يتجاوز العنصر الحد السفلي للوحة. الارتفاع الإضافي المحفوظ لكل صفحة وجهاز لا ينكمش تلقائيًا عند تقليص العنصر؛ هذا يمنع قفزات الواجهة أثناء التحرير.

في «تصدير»، HTML المستقل يحوي صفحات الموقع وروابطها وحركاتها ويبدأ بالصفحة المختارة؛ أما ZIP فيحوي كل الصفحات والملفات المشتركة والأصول التي تم تضمينها. الصور الخارجية التي تمنعها سياسات CORS تحتاج إلى أداة استكمال الوسائط الاختيارية ويمكن أن تفشل بعض روابط الطرف الثالث.

راجع `QA_REPORT_V35.md` و`MERGE_AUDIT_V35.md` للمراجعة والاختبارات وحدود التحقق.
