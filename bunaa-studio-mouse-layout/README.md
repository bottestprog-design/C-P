# بَنّاء Studio V27

نسخة HTML مباشرة. افتح `index.html` أو `Bunaa.html` في المتصفح. `OPEN_FIRST.html` يوجّه إلى `index.html`.

## تحريك العناصر وتغيير مقاسها
- الزر والرابط والصورة والنصوص تبدأ بحجم المحتوى بدل شغل السطر كله. الأقسام والحاويات الهيكلية تظل بعرض كامل افتراضيًا.
- حدّد عنصرًا ثم اسحب مقابض الحافة اليمنى أو السفلية أو الزاوية لتغيير عرضه وارتفاعه. يُحفظ المقاس في بيانات المشروع وعلى نقطة العرض النشطة؛ ومقاس الصورة المرئي يطابق المقاس المحفوظ.
- اسحب عنصرًا فوق عنصر آخر لتغيير ترتيبه، أو ضعه داخل حاوية متوافقة. إفلاته في مساحة فارغة ينقله إلى نهاية المستوى الحالي.
- اسحب مستطيلًا فوق العناصر على مساحة فارغة لتحديد أكثر من عنصر، أو استخدم Shift/Ctrl/Command مع النقر لتبديل التحديد.
- بعد تحديد عنصرين أو أكثر، اختر **تجميع** ثم اختر تخطيط الحاوية: أفقي مرن، رأسي، شبكة، أو مكدّس. يمنع المحرر التجميع بين مستويات مختلفة حتى لا تتغير بنية الصفحة بصمت.
- زر **معاينة** في شريط أدوات مساحة العمل يفتح صفحة مستقلة مولّدة من المشروع الحالي. إذا منع المتصفح النوافذ المنبثقة، تظهر معاينة فعلية داخل المحرر. زر المعاينة القديم لم يُحذف.

## الصيانة والاختبارات
- `source/src/` يحتفظ بوحدات المصدر الـ49، و`bundle-extracted.js` هو ملف التشغيل المدمج.
- `node tests/direct-manipulation-smoke.cjs` يفحص عمليات النموذج والتجميع والمقاسات ومزامنة ملفات HTML مع الحزمة المدمجة.
- Node مطلوب للاختبارات فقط، وليس لتشغيل نسخة HTML المباشرة.
