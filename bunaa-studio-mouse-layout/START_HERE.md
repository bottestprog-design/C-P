# ابدأ هنا — بَنّاء Studio V27

1. فك الضغط، ثم افتح `index.html` (أو `Bunaa.html`).
2. ادخل إلى الاستوديو ثم افتح المحرر.
3. أضف العنصر المطلوب. عناصر المحتوى تبدأ بحجمها الطبيعي؛ الأقسام الرئيسية تبقى بعرض كامل.
4. لتغيير المقاس، حدّد العنصر واسحب المقبض الأيمن للعرض، أو السفلي للارتفاع، أو مقبض الزاوية لكليهما.
5. لتحريك العناصر، اسحب عنصرًا فوق الآخر لتحديد مكانه النسبي. اسحبه داخل حاوية لوضعه بداخلها.
6. للتجميع، اسحب مستطيل تحديد فوق العناصر أو استخدم Shift/Ctrl/Command مع النقر، ثم اضغط **تجميع** واختر أفقي أو رأسي أو شبكة أو مكدّس.
7. اضغط **معاينة** في شريط أدوات مساحة العمل لفتح الصفحة المولّدة في تبويب مستقل. إذا حُظرت النوافذ المنبثقة، تُعرض المعاينة الفعلية داخل المحرر.

## اختبار النسخة
من مجلد المشروع شغّل:

```bash
node tests/direct-manipulation-smoke.cjs
```

هذا الاختبار يحتاج Node.js؛ تشغيل المحرر نفسه لا يحتاج Node.js.
